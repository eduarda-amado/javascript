# 📊 Analisador de Números

Projeto desenvolvido com JavaScript que permite cadastrar números entre 1 e 100 e realizar análises automáticas sobre os valores informados.
[Clique aqui](https://eduarda-amado.github.io/javascript/projetos/analisador-de-numeros/modelo)

---

# 🚀 Funcionalidades

- Adicionar números de 1 a 100;
- Validação para impedir números repetidos;
- Contagem total de números cadastrados;
- Exibição do maior valor informado;
- Exibição do menor valor informado;
- Soma total dos números;
- Cálculo da média dos valores cadastrados.
