# 🎂 Verificador de Idade

Projeto desenvolvido com JavaScript que calcula a idade do usuário com base no ano de nascimento informado.

O sistema também exibe uma imagem correspondente à faixa etária e ao sexo selecionado.
[Clique aqui](https://eduarda-amado.github.io/javascript/projetos/verificador-de-idade/modelo)

---

# 🚀 Funcionalidades

- Entrada do ano de nascimento;
- Seleção de sexo;
- Cálculo automático da idade;
- Exibição dinâmica do resultado;
- Alteração automática da imagem conforme:
  - sexo;
  - faixa etária.

As imagens variam entre:
- bebê;
- jovem;
- adulto;
- idoso.
