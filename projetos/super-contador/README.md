# 🚀 Super Contador

Projeto desenvolvido com JavaScript que realiza contagens personalizadas a partir de valores informados pelo usuário.
[Clique aqui](https://eduarda-amado.github.io/javascript/projetos/super-contador/modelo)

---

# 🚀 Funcionalidades

- Definição do número inicial;
- Definição do número final;
- Escolha do passo da contagem;
- Exibição automática da sequência numérica;
- Inclusão de emojis durante a contagem;
- Validação de dados inseridos.

---

# 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---
