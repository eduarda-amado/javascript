# ✖️ Tabuada

Projeto desenvolvido com JavaScript que gera automaticamente a tabuada de um número informado pelo usuário.
[Clique aqui](https://eduarda-amado.github.io/javascript/projetos/tabuada/modelo)

---

# 🚀 Funcionalidades

- Entrada de número personalizada;
- Geração automática da tabuada;
- Exibição dinâmica dos resultados;
- Interface simples e interativa.

---

# 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

# 🎯 Objetivo do Projeto

Praticar:
- estruturas de repetição;
- manipulação do DOM;
- eventos;
- cálculos matemáticos;
- lógica de programação.

---

# 📚 Aprendizados

Durante o desenvolvimento deste projeto foram praticados conceitos como:

- loops em JavaScript;
- manipulação de elementos HTML;
- atualização dinâmica de conteúdo;
- operações matemáticas;
- interação com usuário.
