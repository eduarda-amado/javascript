# 🔢 Contador Inteligente

Projeto de contador interativo desenvolvido com JavaScript.

O sistema permite incrementar, decrementar e resetar valores dinamicamente.
Além disso, o contador altera automaticamente a cor dos números conforme o valor exibido.

---

# 🚀 Funcionalidades

- Botão de incremento (+);
- Botão de decremento (-);
- Botão de reset;
- Mudança automática de cor:
  - verde para números positivos;
  - vermelho para números negativos;
  - cor padrão para zero;
- Salvamento do contador utilizando LocalStorage;
- Persistência de dados mesmo após atualizar a página.

---

# 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---
