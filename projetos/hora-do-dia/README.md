# 🌤️ Hora do Dia

Projeto desenvolvido com JavaScript que identifica automaticamente o horário do sistema e altera elementos visuais da página de acordo com o período do dia.
[Clique aqui](https://eduarda-amado.github.io/javascript/projetos/hora-do-dia/modelo)

---

# 🚀 Funcionalidades

- Identificação automática do horário atual;
- Exibição dinâmica das horas;
- Alteração automática da imagem;
- Mudança da cor de fundo conforme o horário;
- Diferentes temas para:
  - manhã;
  - tarde;
  - noite.

---

# 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

Praticar:
